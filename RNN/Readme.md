# Генерация имён с помощью рекуррентной нейронной сети (RNN)

## Описание проекта

Данный проект демонстрирует реализацию **символьной рекуррентной нейронной сети (Character-Level RNN)** для генерации человеческих имён.

Модель обучается на наборе из примерно **8 тысяч имён различных культур**, представленных в латинской транскрипции, после чего способна создавать новые имена, которые стилистически похожи на обучающие данные, но отсутствуют в исходном датасете.

Проект также показывает разницу между **ручной реализацией RNN-ячейки** и использованием встроенного слоя **PyTorch `nn.RNN`**, что позволяет лучше понять внутренний механизм работы рекуррентных сетей.

# Данные

Для обучения используется открытый датасет человеческих имён.

Характеристики:

* около **8000** имён;
* латинская транодитерация;
* максимальная длина имени — **16 символов**;
* данные автоматически скачиваются из открытого репозитория.

Поскольку модель работает на уровне символов, каждое имя рассматривается как последовательность отдельных букв.

---

# Архитектура модели

В проекте представлены **две реализации** рекуррентной сети.

## 1. Собственная реализация RNN (`CharRNNCell`)

Модель состоит из следующих компонентов:

* **Embedding** размерности **16**;
* объединение текущего символа и скрытого состояния;
* линейный слой;
* функция активации **tanh**;
* выходной линейный слой, предсказывающий следующий символ.

Такая реализация позволяет увидеть внутреннюю механику работы рекуррентных нейронных сетей.

---

## 2. Реализация на `nn.RNN`

Вторая версия использует встроенный слой PyTorch:

```python
nn.RNN(...)
```

Данный вариант значительно сокращает объём кода и является рекомендуемым способом построения RNN в реальных проектах.

# Обучение модели

Используются следующие параметры обучения:

| Параметр                | Значение         |
| ----------------------- | ---------------- |
| Функция потерь          | CrossEntropyLoss |
| Игнорирование паддингов | Да               |
| Оптимизатор             | Adam             |
| Размер батча            | 32               |
| Количество итераций     | 1000             |

Во время обучения значение функции потерь визуализируется в режиме реального времени, что позволяет наблюдать за процессом сходимости модели.

# Генерация новых имён

После обучения модель способна генерировать новые последовательности символов.

Используется **семплирование с температурой** (`temperature`), позволяющее управлять разнообразием результатов:

* низкая температура → более предсказуемые имена;
* высокая температура → более разнообразные и необычные варианты.

Также можно задать **начальную последовательность символов (seed phrase)**, после чего модель продолжит её самостоятельно.

Например:

```python
generate(seed="Sherl", temperature=0.8)
```
